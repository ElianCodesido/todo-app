# Task Manager App

A task management application built with React, TypeScript and Node.js.

## Features

- Create multiple task lists
- Add, edit, and delete tasks
- Mark tasks as completed
- Draggable windows
- Backend API persistence (in-memory)

## Tech Stack

- React
- TypeScript
- Node.js
- Vite
- CSS

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
